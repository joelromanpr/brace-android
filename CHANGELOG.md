# Changelog

Brace Android has no published version yet. This page records releases; the [component list](docs/coverage.md) tracks work in source.

## Unreleased

- Established the versioned token system, BraceTheme, accessibility baseline, and multi-module Android artifacts.
- Added source previews for core controls, forms, overlays, navigation, selection, date and time, icons, and data tables.
- Added the searchable Android catalog, two runnable operations examples, and the public showcase.
- Prepared CI, API checks, documentation checks, Maven metadata, signing, and a manual release workflow.

The first release will name its supported components and known limits here. Source previews are not a promise of stable API.
