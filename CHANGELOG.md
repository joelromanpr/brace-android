# Changelog

This page records published versions. The [component list](docs/coverage.md) tracks the readiness of each API separately.

## 0.1.0-alpha01

- Published eight aligned preview artifacts on Maven Central: `brace-foundation`, `brace-core`, `brace-icons`, `brace-blueprint-icons`, `brace-blueprint-icons-next`, `brace-select`, `brace-datetime`, and `brace-table`.
- Included versioned tokens, `BraceTheme`, controls, forms, navigation, overlays, selection, date and time inputs, icon APIs, and a data table with viewport, keyboard, selection, editing, and accessibility work.
- Added the searchable Android catalog, electric fleet and mission control examples, and a public showcase with real emulator captures.
- Included sources, documentation artifacts, and signed Maven publication metadata. The [separate consumer project](verification/consumer-smoke/README.md) can check resolution from Maven Central.

This alpha makes the code installable; it does not make every behavior complete. The [inventory](docs/coverage.md) still marks **0 of 122 applicable rows stable**. APIs and interactions may change during the preview series. Check each component guide for its known limits.
