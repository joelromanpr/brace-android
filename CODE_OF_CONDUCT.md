# Code of Conduct

We want a welcoming, technically rigorous project. Be respectful, assume good intent, give actionable feedback, and make room for people with different backgrounds and accessibility needs. Harassment, personal attacks, sexualized language or images, and publishing another person's private information are not acceptable.

Maintainers may edit or remove comments, close discussions, or restrict participation to protect contributors. Report conduct concerns privately to the maintainer through the contact method listed on the repository owner's GitHub profile. If no private contact is available, do not post sensitive details publicly; the maintainer must establish a private contact before the project can accept confidential reports. Reports will be reviewed by a maintainer, with a response target of seven days. The maintainer will avoid sharing identifying information beyond what is needed to investigate.

This policy applies in repository issues, pull requests, discussions, and project events. Maintainer decisions can be appealed privately to the repository owner.
