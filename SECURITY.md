# Security policy

## Supported versions

After the first release, security fixes target the latest stable minor release. Older minors may receive a backport when the impact and maintenance cost justify it. Before the first release, use the latest commit on `main`; there is no supported published version yet.

## Reporting

Please use **Security → Report a vulnerability** on the [repository](https://github.com/joelromanpr/brace-android/security) when private vulnerability reporting is enabled. Do not put exploit details or sensitive data in a public issue. If that button is absent, use a private contact listed on the repository owner's GitHub profile. The repository must enable private vulnerability reporting before it can promise a reliable confidential channel.

Include the affected release or commit, reproduction steps, potential impact, and whether public disclosure has occurred. A maintainer aims to acknowledge a private report within seven days, coordinate a fix and advisory, and credit the reporter if requested. No disclosure deadline is imposed without discussion with the reporter.
