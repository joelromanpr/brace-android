# Support

- Use [Discussions](https://github.com/joelromanpr/brace-android/discussions) for usage and design questions once the maintainer enables it in repository settings.
- Until Discussions is enabled, use a **Question or support** issue form. Please search existing issues first and include artifact versions, Android version, and a small reproducer.
- Use a **Bug report** issue for a reproducible library defect and an **Accessibility issue** for an access problem.
- Send vulnerabilities through the private path in [SECURITY.md](SECURITY.md).

This is a volunteer-maintained project with no guaranteed response time. Do not include credentials, personal data, or private customer data in issues.
