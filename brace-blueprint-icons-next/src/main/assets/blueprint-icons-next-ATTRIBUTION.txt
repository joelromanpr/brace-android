Brace Android transcribes SVG viewBox and path data into a compact JSON manifest and
converts the paths to Compose ImageVectors at runtime. The one source rect with no
width in filled magnifying-glass-lines.svg has zero width and draws no pixels; it is
omitted from the vector path. This artwork remains distinct from Brace's original icons.
