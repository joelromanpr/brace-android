# Third-party attribution and reference sources

Brace Android is an independent Android implementation. Its name, APIs, visual system, Kotlin code, and documentation are authored for this repository. The coverage inventory compares Brace against [Palantir Blueprint](https://github.com/palantir/blueprint) at the exact commit recorded in [BLUEPRINT_BASELINE.md](../BLUEPRINT_BASELINE.md). Blueprint is distributed under the [Apache License 2.0](https://github.com/palantir/blueprint/blob/a60d4c92257612808fbfac81cfeee4fcba91a8b4/LICENSE). Blueprint component names and documentation links in the inventory identify the comparison source; they do not imply endorsement or that Blueprint code has been copied.

No Blueprint icon files, code, or artwork are bundled in the current Brace source. The `brace-icons` artifact contains 11 original 24-unit vector drawings authored for Brace Android under the root Apache-2.0 license. The [manifest](../brace-icons/src/main/assets/brace-icons-manifest.json) records the name, origin, author, source file, and license for each drawing and is packaged in the AAR. These drawings are a small independent set and do not imply Blueprint glyph parity. Any future imported third-party asset or copied code must have its source commit, license, copyright notice, modifications, and affected artifact recorded here and reviewed before merge.

The root [LICENSE](../LICENSE) applies to Brace-authored material. Dependency licenses remain with their respective packages and should be checked in release artifacts and Maven metadata.
