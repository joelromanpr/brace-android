# Third-party attribution and reference sources

Brace Android is an independent Android implementation. Its name, APIs, visual system, Kotlin code, and documentation are authored for this repository. The coverage inventory compares Brace against [Palantir Blueprint](https://github.com/palantir/blueprint) at the exact commit recorded in [BLUEPRINT_BASELINE.md](../BLUEPRINT_BASELINE.md). Blueprint is distributed under the [Apache License 2.0](https://github.com/palantir/blueprint/blob/a60d4c92257612808fbfac81cfeee4fcba91a8b4/LICENSE). Blueprint component names and documentation links in the inventory identify the comparison source; they do not imply endorsement or that Blueprint code has been copied.

The `brace-icons` artifact contains 11 original 24-unit vector drawings authored for Brace Android under the root Apache-2.0 license. Its [manifest](../brace-icons/src/main/assets/brace-icons-manifest.json) records each drawing. The original default registry remains separate from imported assets.

The optional `brace-blueprint-icons` artifact redistributes **Palantir Blueprint legacy icon artwork** from `@blueprintjs/icons` 6.13.0 in the pinned Blueprint commit `a60d4c92257612808fbfac81cfeee4fcba91a8b4`. Source metadata: `packages/icons/icons.json`; source SVGs: `resources/icons/16px` and `resources/icons/20px`; source license: `packages/icons/LICENSE`. The files are Apache-2.0 licensed. We extracted each SVG `path d` and `viewBox` into a compact [asset manifest](../brace-blueprint-icons/src/main/assets/brace-blueprint-icons.json); no visual path edits were intended. The manifest records SHA-256 for every original SVG and for `icons.json` and `LICENSE`, and the [generator](../scripts/generate_blueprint_icons.py) can compare it byte-for-byte with the pinned checkout. The [license copy](../brace-blueprint-icons/src/main/assets/blueprint-icons-LICENSE.txt) and [attribution/modification notice](../brace-blueprint-icons/src/main/assets/blueprint-icons-ATTRIBUTION.txt) are packaged in the optional AAR. Brace Android is independent of Palantir and does not imply endorsement.

The root [LICENSE](../LICENSE) applies to Brace-authored material. Dependency licenses remain with their respective packages and should be checked in release artifacts and Maven metadata.
