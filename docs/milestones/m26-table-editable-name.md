## Source in this slice

- `BraceEditableColumnName` provides a token-driven, saveable single-line header draft with select-all-on-focus, required-name and caller validation, IME Done/Enter commit, Escape cancel, and localized accessibility actions.
- `BraceDataTable` keeps a separate controlled header edit session by stable column key. Opted-in headers support selected-column Enter/F2, double-tap/double-click, and an accessibility edit action. Offscreen headers are revealed; the active resize grip yields to the editor; unavailable cell Edit actions are hidden; another header cannot discard an active draft; commit/cancel return table focus.
- The API snapshot, 13 focused header-edit tests, 120-row interactive catalog sample, independent Maven consumer, guide, and pinned inventory row advance together. The sample uses the extracted `TableCatalogSample` and preserves M14 measured row-header width, M18 focused resize-handle identity, and M22 semantic editor spacing.
